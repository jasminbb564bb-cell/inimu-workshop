RETURNS

返品について

商品に不備があった場合と、お客様都合の場合で条件が異なります。

不良品の場合

商品が破損・汚損していた場合は、返送料を店舗負担で交換します。配送途中の破損なども店舗へ連絡してください。メール便は保証対象外です。

お客様都合の場合

商品到着後7日以内に返品希望の意思を連絡してください。往復送料・振込手数料はお客様負担です。

返品できない場合

到着から8日以上経過した商品、使用済みの商品、汚損・破損された商品、開封済みの商品、加工された商品は返品できません。

返品送料

お客様都合の場合はお客様負担。不良品の場合は店舗負担です。
