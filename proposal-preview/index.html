Web Experience Redesign

学習用・企画提案書 FINAL
中間 諭 / 2026.10.01

見た瞬間に、次の一歩がわかる。
読むWebから、見れば分かるWebへ。

情報を増やして読ませるのではなく、目的を分け、迷わず選べる入口をつくる。

CONCEPT

企画の背景

inimuの価値を、情報量ではなく
体験の流れとして伝える。

BACKGROUND

inimuには、商品、ワークショップ、素材、地域、職人、ブランドストーリーなど、伝えるべき価値が多くあります。課題は情報が足りないことではなく、必要な情報へたどり着く入口が分かれきっていないことです。

APPROACH

最初に「買う」と「つくる」を分ける。そこからHATENKO / WANOWAの個性へ進む。目的に合わせて情報を段階的に見せ、商品・体験・問い合わせへ自然につなげます。

TWO SIGNATURES

inimuをかたちづくる、2つの香り。

01 HATENKO　伝統と革新で、日常を揺らす香り。

02 WANOWA　土地と素材から生まれる、記憶に残る香り。

ブランドを商品一覧の一部ではなく、最初に意味が伝わる入口として配置します。

01 CAUSE

課題

価値はある。
でも、最初の一歩で伝わりにくい。

FACT / OBSERVATION

高評価なのに、なぜ予約につながらないのか。

既存の声には、次のような評価が見られます。

  • 香りが心地よかった
  • 自分用・親子用など目的に合った
  • 初めてでも安心して参加できた
  • 好きな香りを見つけられた

体験の満足度は高い一方、Web上では価値が一つの流れにまとまりきっていません。

INSIGHT / HYPOTHESIS

「何が良いか」は見えても、「なぜinimuを選ぶのか」までは見えにくい。

土地・素材・職人・記憶といった固有の価値を、次の行動につなげる設計が必要です。

課題の読み方
情報を足す前に、入口を整理する。目的が決まれば、必要な情報だけを適切な順番で見せられる。

02 HYPOTHESIS

仮説

見えない価値を、
見える導線へ。

A

情報設計

利用目的に合わせて、入口と深掘りを分ける。

B

体験価値

「自分に合う香り」「なぜ選んだか」を残す。

C

ブランド

HATENKO / WANOWAを前面に出し、背景から商品へつなげる。

D

顧客の声

会員登録と体験後アンケートを改善の接点にする。

Web公開後のアクセスデータ、アンケート、顧客の反応によって検証する仮説です。

03 IDEA ①

Web構成

最初に目的を選び、
その後にinimuの価値へ進む。

TOP → SHOP / EXPERIENCE

TOP
SHOP買う
香り・商品・ブランドを探す
EXPERIENCEつくる
ワークショップ・予約・FAQ

SHOP

SIGNATURE STORIES
HATENKO / WANOWA → ストーリー → 商品。

EXPERIENCE

体験の概要 → 4タップのアンケート → FAQ → 予約。

TOPでは「買う」と「つくる」を明確に分けます。ユーザーは自分の目的を選び、必要な情報だけへ進めます。

MAKE YOUR SCENT　選ぶだけでなく、つくる。　SHOP → EXPERIENCE

03 IDEA ②

体験後アンケート

30秒・4タップで、
体験の記憶を残す。

自由記述だけでは負担になるため、まず直感で選べる4つの入口を置き、必要な場合だけ一言を添えてもらいます。

診断ではなく、言葉のきっかけ

選択結果を断定せず、体験後の気づきを引き出します。

整整った深深呼吸した探好きが見えた残記憶に残った

整：すっきりした / 深：集中した / 探：好きが見えた / 残：印象が残った

STEP 1近い言葉を選ぶ
STEP 2理由を選ぶ
STEP 3記憶に残ったもの
STEP 4あれば一言

直感・理由・記憶を集め、次のWeb、商品、体験改善へつなげます。

04 VERIFICATION

検証

数字だけでなく、
何が選択に残ったかを見る。

既存の声・口コミ一般的な満足・不満
→
体験後アンケート顧客自身の反応
→
Web上の行動固有の価値を発見

口コミで分かること：楽しい・丁寧・初心者でも安心・好みの香りが見つかる。

口コミだけでは分からないこと：なぜ選んだか・何を期待したか・どこで知ったか・予約の決め手。

分からないことを、体験後アンケートとWeb上の行動で補います。

検証するもの

HATENKO / WANOWA STORY閲覧
STORY → 商品詳細
SHOP → EXPERIENCE
滞在時間・離脱 / 回答内容

STORYから商品詳細へ進む動きが増え、体験後の回答が次の改善につながる。

何が見られ、選ばれ、心に残ったかを組み合わせて改善します。

VISITOR VALUE / HYPOTHESIS

外部レビューでは、香水作り体験について「日本語が流暢でないと難しい」という趣旨の指摘が見られた。訪日旅行者にとって、言語や予約導線が参加障壁になっている可能性がある。

単なる英語化ではなく、土地・素材・文化の背景を知る → 香りを体験する → 商品を購入する → 日本の記憶として持ち帰る、という導線を将来案として検討する。

「香水を作る体験」ではなく、
「日本の香り文化を持ち帰る体験」へ。

現時点ではJP / EN表示と外部予約先の明示まで実装。
自社HP予約・外部予約枠との一元管理・GA4連携は将来拡張案。
